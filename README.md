# Figzen

Figzen is a minimal, local-first Figma plugin that converts a selected Figma Frame into an editable Godot 4 `.tscn` scene.

## What it exports

Supported mappings:

- Frame / Group / Section → `Control` (auto-layout mode recorded as metadata)
- Rectangle → `ColorRect`, or `Panel` with corner-radius metadata when rounded
- Rectangle with an image fill → `TextureRect` placeholder
- Text → `Label`
- Line → `Line2D`
- Ellipse → `Control` with shape/fill metadata
- Component / Component Set / Instance → `Control`, recursively preserving supported children
- Vector / Boolean operation / Star / Polygon → `Control` with original-type metadata
- Any other Figma node → `Control` with a warning

Preserved:

- Node names (sanitized, with duplicate siblings de-duplicated)
- Recursive hierarchy
- Position and size
- Visibility
- Opacity (as `modulate`)
- Rotation
- Solid fill colors
- Text content, font size, font color, and horizontal alignment
- Line stroke color, stroke width, and points

Unsupported details are surfaced as warnings in the plugin UI after export rather than being silently dropped.

The plugin creates the `.tscn` text in the Figma plugin runtime and packages it into a ZIP entirely in the plugin UI. There is no backend, database, account system, cloud storage, telemetry, analytics, AI service, or network call.

## Build

Requirements:

- Node.js 18+
- TypeScript available through `npm install`
- `zip` command available on the build machine

Run:

```bash
npm install
npm run typecheck
npm run test
npm run build
```

The build outputs:

- `dist/manifest.json`
- `dist/code.js`
- `dist/ui.html`
- `figzen-plugin.zip` (the ZIP to attach to a GitHub release)

## Load into Figma

1. In Figma Desktop, open **Plugins → Development → Import plugin from manifest…**.
2. Select this project's `manifest.json`.
3. Run Figzen from **Plugins → Development**.
4. Select a Frame and click **Export selected Frame**.
5. Extract the downloaded ZIP into a Godot 4 project.
6. Open the generated `.tscn` in Godot.

## Test example

The repository includes `examples/sample.tscn`. It demonstrates a `Control` root, a colored `ColorRect`, a `Label`, and a nested `Control` containing another `ColorRect` and `Label`.

## Known limitations

- Ellipse, vector, boolean, star, and polygon geometry is preserved as a placeholder `Control` with metadata; the actual shape drawing must be implemented in Godot.
- Image fills export as a `TextureRect` placeholder; the binary texture asset is not yet exported.
- Gradients, strokes (except lines), corner radii (except via `Panel` metadata), effects, typography family/weight/style, text wrapping, auto-layout constraints, masks, prototype interactions, and Figma-specific effects are not exported.
- Geometry is based on Figma node positions relative to the immediate parent. This preserves visible placement but is not a full reproduction of Figma's layout engine.
- Figma node names containing path separators are sanitized on export.
- Large frames can create large UI messages because the generated scene is sent from the plugin code to the UI for ZIP packaging.
- The project can be typechecked and built outside Figma, but actual Figma-runtime behavior and Godot import behavior should still be smoke-tested in Figma Desktop and Godot 4 respectively.

## Future improvements

The cleanest next additions are:

1. Auto-layout → Godot containers and anchors.
2. Typography mapping including font family, weight, line height, and wrapping.
3. Full corner radius and border/stroke mapping.
4. SVG/vector path export and binary image export into the ZIP.
5. Component/variant metadata and reusable Godot scenes/resources.
6. Export settings for root node type, pixel snapping, and naming policy.
